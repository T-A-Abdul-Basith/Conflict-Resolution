# Conflict Resolution
A small git repo to teach how someone can handle conflicts in git

This 'game' is meant to be played by three players/developers.

Each player must first create their own branch to work on, then write their own code, and push it to the remote
> [!NOTE]
> you may need to use ```git push -u origin <branch name>``` since the branch doesn't exist online

After this, a designated team leader among the 3 players will, with the help of the other 2 players, merge all the branches into one single directory and voila

The provided check file (```check``` for Linux, ```check.exe``` for Windows) will allow you to confirm wether merging happened successfully on your system side
